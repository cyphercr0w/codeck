# Codeck Competitive Research — March 2026

## Executive Summary

Codeck occupies a unique gap: **nobody sells "self-hosted Claude Code in a box"**. Anthropic's own Claude Code Web is cloud-only and GitHub-only. Coder targets enterprise. OpenHands has no persistence. The individual developer / small team self-hosted market is wide open.

Our strongest differentiators: persistent AI memory between sessions, always-on sandbox from any device, pre-configured MCP/skills, BYOK cost model, scheduled autonomous agents.
